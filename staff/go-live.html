3 • CUTOVER

Launch-day control sequence

These steps remain deliberately procedural. The browser does not execute a production database import.

BEFORE

Freeze & protect

  • Freeze source-register changes.
  • Create and verify a backup.
  • Confirm named accounts and roles.
  • Keep rollback instructions available.
MIGRATE

Controlled import

  • Use only validated source records.
  • Record imported and rejected totals.
  • Do not delete source registers.
  • Retain an exception log.
VERIFY

Reconcile

  • Reconcile totals against source evidence.
  • Spot-check resident references.
  • Test staff and resident workflows.
  • Review audit events.
ACCEPT

Close the launch

  • Run post-launch smoke tests.
  • Confirm monitoring is active.
  • Keep rollback available.
  • Record management/IT acceptance.
Privacy and authorization boundary: do not load confidential resident records into an unauthorized staging environment. A validated CSV export is only a reviewed migration package; production import must occur through the secured server/database process after the required THA IT / management authorization.
