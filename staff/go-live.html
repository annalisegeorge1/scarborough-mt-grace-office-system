3 • CUTOVER

Launch-day control

Before launch

  • Freeze changes to source spreadsheets.
  • Take a verified backup.
  • Confirm staff accounts and roles.
  • Import only validated records.

During cutover

  • Record import totals and rejected rows.
  • Spot-check resident references.
  • Confirm public tracker and staff portal.
  • Do not delete source registers.

After launch

  • Reconcile record counts.
  • Test backup restoration.
  • Review audit events.
  • Keep rollback available.

Approval

The checklist and migration package support a launch decision; they do not authorize production use by themselves.

Privacy: do not place real resident records into the browser training workspace. For production migration, the import must occur through the secured server with role checks, audit logging and encrypted storage.
Go-live tools are administrative controls. Production security is enforced by the deployed server, database and identity system.
