Practice workflows

Resident enquiry

Create a test case, assign it, set a follow-up, add a public-safe update and confirm the resident tracker reveals no private notes.

Community matter

Link several test case references to one broader matter, record an agency referral and publish only the approved public summary.

Town hall / project

Create an initiative, add an action item, update its timeline and verify that internal notes remain staff-only.

Records & reporting

Register a test document, classify sensitivity correctly, run a report and verify that only approved public material is exposed.
