# Incident Response Baseline

## Severity
- Critical: confidentiality breach, data loss, account compromise, tracking failure affecting many records, or unsafe public exposure.
- High: major workflow unavailable or repeated incorrect records/statuses.
- Medium: degraded function with a usable workaround.
- Low: cosmetic or minor usability issue.

## Response
1. Record the incident and time detected.
2. Limit impact; disable or isolate affected function if necessary.
3. Preserve evidence and audit information.
4. Notify the responsible manager for High/Critical incidents.
5. Correct, test and document the fix.
6. Validate affected records before closure.
7. Record any resident/public communication required.

Critical incidents should trigger a review of whether pilot operations must pause or rollback.
